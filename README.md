## 韩国住宅 IP 贵在哪，怎么判断你拿到的是不是真的

机房 IP 的 ASN 指向数据中心，TikTok、Netflix、ChatGPT 这类平台会把它判成代理；住宅 IP 由本土宽带运营商分配，IP 数据库里标成 residential，平台侧看到的是“一个韩国本地用户在上网”。WePC 官方把韩国这档写成「家宽」+「双 ISP」——双 ISP 指这个 IP 同时带两个运营商属性，风控模型里更接近真实家庭用户。

官方标称和你手上这台是不是住宅段，是两回事。开通后第一时间跑一遍：

- **ASN 查询**：用 ipinfo.io 或 ip.sb 看 ASN 是否韩国本土 ISP，而不是机房或云厂商。
- **风险分**：scamalytics 查风险评分，住宅 IP 一般分数偏低（第三方测评常给 10–25 区间作参考），分数偏高说明这个 IP 被用脏了。
- **归属与解锁**：查 IP 的 country / region 是否为韩国，再登录 Netflix、TikTok 看 region 和播放是否正常。
- **带宽实测**：speedtest 看实测是否接近 100Mbps。
- **回程路由**：traceroute 看是否走优化线路，而不是绕路。

流媒体和 TikTok 的解锁能力会随 IP 段、平台策略变化，今天的实测不等于长期保证，先用后付更稳。👉 [从 WePC 韩国这档开始，先月付试一台](https://wepc.au/aff.php?aff=300)
